      Profile warnings

        First-run guide

        Welcome to Xbox Input Bridge

        This extension works only in supported Xbox Cloud Gaming browser pages. It does not create a Windows controller, work in installed games, or access the network.

        Input is never captured automatically. Starting capture always requires your explicit action, and Escape releases it.

        PC-to-controller quick guide

        Stick
        A directional control. WASD usually becomes the left stick; mouse movement becomes the right stick.
        Trigger
        A pressure-style control commonly used for fire, aim, accelerate, or brake.
        Buttons and D-pad
        Games decide what A/B/X/Y, bumpers, Menu/View, and directional-pad controls do.
